# Astoria Study Abroad Website

A modern, responsive website for Astoria Study Abroad agency built with React, Vite, and TailwindCSS.

## Features

- 🎨 Modern, clean design with brand colors
- 📱 Fully responsive across all devices
- 🚀 Fast performance with Vite
- 🎯 SEO-friendly structure
- 🌍 5 complete pages: Home, About, Services, Countries, Contact
- ✨ Smooth animations and transitions
- 📝 Contact form with validation

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **TailwindCSS** - Utility-first CSS framework
- **React Router** - Client-side routing
- **Lucide React** - Icon library

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository or navigate to the project directory
2. Install dependencies:

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

The site will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```
